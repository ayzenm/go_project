# Журнал решений

## Завершение пилота и уточнение плана

В отдельной копии выполнены правки TensorFlow API, initializer, бинарного NumPy I/O и отсутствующего пути; исходники первой попытки сохранены. Плотный пилот без pruning завершился с exit code 0, временем обучения 164,007 с и final test accuracy 97,96%. Его SGD/batch 64/train 60 000 без validation отличаются от Figure 4a; результат не назван воспроизведением. Настройки основного Adam-эксперимента не подбирались по этому результату.

По Appendix G.1 зафиксированы split 55 000/5 000, test 10 000, оценка каждые 100 шагов. Split seed 42 — наш выбор, а не заявленный авторами seed. Будущие запуски считают фактические gradient updates и задают TF seed после каждого reset_default_graph: пилот показал 49 947 строк обучения при счётчике 50 000. Random pruning на тех же послойных количествах теперь запланирован как обязательная проверка на двух уровнях; первым сокращается только один из уровней при нехватке времени.
