# A3 Lottery Ticket Hypothesis

Материалы pre-registration для Айзенберг Марьям Гусейновны и Храмых Алёны Дмитриевны. Есть документированная неудачная попытка без правок и успешный плотный пилот с правками совместимости. Основной эксперимент Figure 4a ещё не выполнен: на этапе pre-registration он зафиксирован как план.

## Содержимое

- `docs/A3_pre_registration_final.docx`: восемь разделов, уточнённая Figure 4a, фактический результат попытки.
- `logs/as_is_run.md`: окружение, команда, длительности, ошибка и ссылка на выполненный Colab.
- `scripts/run_as_is.py`: повторяемая процедура проверки в свежем Colab/Linux-каталоге; не запускает исправленную реализацию.

## Повторение диагностики

В свежем каталоге Colab с T4 выполните `python scripts/run_as_is.py`, указав путь к скачанному скрипту. Скрипт клонирует зафиксированный commit, устанавливает зависимости и вызывает upstream runner. Ненулевой exit code здесь ожидается. Скрипт подготовлен после ручной проверки; сам этот файл в Colab ещё не выполнялся. Нельзя считать его протестированным обучением.

Исторический стек TensorFlow не зафиксирован upstream. Текущий pip freeze — свидетельство конкретной неудачи, а не рабочее окружение обучения. Не устанавливайте произвольный современный TensorFlow и не называйте это воспроизведением оригинала. Последующие исправления хранить отдельно от неизменённой попытки, с patch и новой фиксацией окружения.

## Пилот с правками

Плотная LeNet с SGD 0,1, batch 64 и 60 000 train завершила upstream-счётчик 50 000 за 164,007 с, final test accuracy 97,9600%, final test loss 0,0716389. У неё нет validation, pruning и оценки early stopping. Это не проверка гипотезы Figure 4a. Фактически зарегистрировано 49 947 строк обновления: upstream увеличивает счётчик и на исключении конца эпохи. Также reset_default_graph сбрасывает TF seed: train_order_seed=0 не означает полностью воспроизводимую инициализацию. Основной эксперимент должен явно исправить обе особенности и создать validation split.

Для повторения из `/content`, где уже есть неизменённый `/content/lottery_ticket` и установлены его зависимости:

```bash
python scripts/prepare_compatible.py /content/lottery_ticket /content/A3_compat/lottery_ticket /content/compatibility.patch
```

Затем скопируйте `scripts/pilot_compatible.py` в `/content/A3_compat/pilot.py` и выполните его из `/content/A3_compat`: `python pilot.py`. Названия каталога и пути к MNIST заданы явно, как в выполненном пилоте. Подготовка остановится, если целевой каталог уже существует. Исходный код не перезаписывается. Настройки SGD/batch/данные намеренно сохранены для проверки исходной реализации. API compat.v1 и Glorot initializer не гарантируют побитовой идентичности историческому TensorFlow.

## Исходные журналы и следующий этап

Полные исходные логи, pip freeze, patch и веса собраны в Colab в `/content/A3_evidence_complete.zip`. Автоматическое скачивание через data-ссылку запрещено политикой браузера; пользователь должен скачать этот архив через Files и включить его в репозиторий. Локальные JSON/описание — точная запись увиденных выводов, не замена полной копии сырых журналов. Выполненные ячейки сохранены в приватном блокноте пользователя; доступ преподавателя следует проверить перед сдачей, не меняя доступ автоматически.

Для финала курса предстоит выполнить основной Adam-протокол из конфигурации, три сида, контроли и графики. Это не требование получить все результаты до pre-registration.
